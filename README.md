# Incident Manager (МИ)

Проработка нового приложения **Axxon Incident Manager** — рабочего места оператора для обработки инцидентов от систем видеонаблюдения и охраны. Репозиторий содержит продуктовые документы и работающий прототип интерфейса оператора.

Всё содержимое — материалы этапа проектирования: требования, правила жизненного цикла инцидента и кликабельный прототип для согласования. Production-кода здесь нет.

## Прототип

| Файл | Что это |
|---|---|
| [prototype/index.html](prototype/index.html) | Рабочее место оператора: очередь инцидентов, карточка обработки по сценарию, видеомонитор и карта. Открывается двойным кликом, сборка и сервер не нужны |
| [prototype/app.js](prototype/app.js) | Вся логика и демонстрационные данные: состояния инцидентов, сценарии обработки, права, эскалация, эмуляция работы коллег |
| [prototype/styles.css](prototype/styles.css) | Оформление, светлая и тёмная темы, адаптивные раскладки |
| [prototype/groups.html](prototype/groups.html) | Отдельный ранний прототип управления группами и устройствами. Из него взято дерево объектов для основного прототипа |

### Что показывает прототип

Очередь с фильтрами и группировкой по объектам, взятие инцидента в работу, пошаговый сценарий обработки с обязательными шагами, приостановку и возобновление, эскалацию с выбором адресата, перехват чужого инцидента, групповую обработку, нормативы реакции с обратным отсчётом, перерыв оператора, горячие клавиши, светлую и тёмную темы. Видеомонитор и планы объектов нарисованы примерами прямо в файле, поэтому прототип работает без сервера и без доступа к камерам.

### Как связаны документы

Видение задаёт требования. Первая версия правил превращает их в жизненный цикл инцидента, и по ней собран прототип. Анализ находит в ней противоречия — например, что адресат эскалации не может принять адресованный ему инцидент без права отъёма чужих. Вторая версия эти противоречия устраняет и описывает целевую модель.

**Важно:** прототип пока живёт по первой версии правил. Таблица расхождений с целевой моделью — в разделе §17 второй версии.

## Термины

Полный словарь с расшифровкой сокращений — в §1 [второй версии правил](002%20States%20rules%20IM.md). Коротко: **МИ** — менеджер инцидентов, **SLA** — отведённое время на реакцию и на закрытие инцидента, **сценарий** — пошаговая инструкция обработки под тип события, **эскалация** — передача инцидента другому ответственному, **перехват** — изъятие инцидента у работающего оператора.

## Как посмотреть прототип

Откройте `prototype/index.html` в браузере. Нужен интернет — из сети подгружаются шрифты Inter и Material Symbols; без него всё работает, но иконки будут показаны текстом.

Полезное при первом запуске:

- `?` — список горячих клавиш;
- `F1` — регламент обработки инцидента;
- кнопка солнца в правом верхнем углу — переключение светлой и тёмной темы;
- меню оператора справа сверху — перерыв и выбор адресата эскалации по умолчанию;
- через 10–30 секунд коллеги начнут разбирать события из очереди — так видно поведение чужих инцидентов и работу перехвата.
