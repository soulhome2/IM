# Срабатывание скиллов IM

Набор запросов: какой скилл Claude Code вызывает первым на запрос в свежей сессии этого репозитория. Проверяет описания (`description`) скиллов [im-review](../skills/im-review/SKILL.md), [im-fsm](../skills/im-fsm/SKILL.md), [im-fix](../skills/im-fix/SKILL.md) — и что они не перехватывают чужие запросы, а плагины не перехватывают их.

Прогон — после правки `description` любого скилла, нового скилла или плагина:

```bash
python3 .claude/evals/run_triggers.py            # все запросы, 4 сессии одновременно
python3 .claude/evals/run_triggers.py 3 17 21    # только эти номера
```

Каждый запрос — свежая сессия `claude -p` в режиме plan, без Bash, Edit, Write и MCP: файлы не меняются. Сессия гасится на первом вызове скилла, после трёх других инструментов или через 90 с. Стоит денег — в CI не запускается. Скрипт ищет `claude` в PATH, затем в расширении VS Code; свой путь — переменная `CLAUDE_BIN`.

«Ожидается» — один из трёх скиллов или «нет»: ни один из трёх (другой скилл или ответ без скилла — оба верны). Метрики — по каждому из трёх: precision — из вызовов скилла сколько по делу, recall — из запросов для скилла сколько его вызвали.
