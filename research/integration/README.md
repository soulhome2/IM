# Исследование: встраивание операторской части МИ в облако

Цель — понять, как операторскую часть Incident Manager (прототип этого репозитория) встроить в облако AxxonSoft: в какой продукт, через какие API, с какой авторизацией и правами, что уже есть и чего не хватает.

Исследование начато 2026-10-28. Результаты лежат здесь, чтобы не изучать репозитории заново.
