Тесты API операторской части

Сценарии и случайные прогоны: те же запросы, что у интерфейса. Ответы сверяются со схемами openapi.json. Открывается двойным кликом — тогда проверяется встроенный сервер прототипа. Тестовый стенд бэкенда — api.html?api=https://адрес: нужны служебные операции /test/reset и /test/clock (README машины, «Тестовый стенд»). Петля — api.html?api=loopback со страницы по http: тот же встроенный сервер, но по сети, за Service Worker; запуск — python3 tools/check_loopback.py.
