# Промпты

Промпты для ИИ: разовые вопросы и вопросы внешним ИИ — за вторым мнением. Промпт, который запускается регулярно и по одному порядку, переносится в скилл [.claude/skills/](../.claude/skills/), а здесь удаляется — чтобы одно и то же не жило в двух местах.

В начале каждого файла — дата, коммит, на котором промпт написан, для какого ИИ и зачем. Промпт называет файлы и цифры репозитория, они устаревают: перед запуском сверить с нынешним состоянием. Ответ ИИ — это ревью: он кладётся в [reviews/](../reviews/README.md) по принятому там порядку, а не сюда.
