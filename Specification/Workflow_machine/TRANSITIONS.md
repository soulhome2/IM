# Переходы машины состояний

Собрано из [`workflow_schema.v1.json`](workflow_schema.v1.json) скриптом `tools/build_workflow.py`. Руками не править: правится машина, затем сборка. Это то, что машина делает на самом деле; что задумано — в правилах, §6. Строки правил ссылаются на переходы по идентификатору в первой колонке.

## Права

Каталог прав машины (`permissions`) и где каждое право проверяется. Формат ключа и смысл областей `own` и `any` — в правилах, §5.

| Право | Что разрешает | Где проверяется |
|---|---|---|
| `incident:claim` | Взять новое, возобновить свой отложенный; перехватить и переоткрыть — вместе с их правами. Без него инцидент в работу не попадает | `claim` Взять<br>`resume` Возобновить<br>`takeover` Перехватить<br>`reopen` Переоткрыть |
| `incident:accept` | Принять переданное мне или моей дежурной группе | `accept` Принять |
| `incident:hold` | Отложить свой инцидент с указанием причины | `hold` Отложить |
| `incident:release` | Вернуть свой инцидент в очередь; отклонить адресованную передачу | `reject` Отклонить<br>`release` Вернуть в очередь |
| `incident:close` | Закрыть свой инцидент с результатом: «Обработан» — когда сценарий пройден до конца; «Ложная тревога», «Дубликат», «Плановая проверка», «Прервано» — без сценария | `close` с результатом «Обработан»<br>`close` с результатом «Ложная тревога»<br>`close` с результатом «Дубликат»<br>`close` с результатом «Плановая проверка»<br>`close` с результатом «Прервано: обработка невозможна» |
| `incident:close:unprocessed` | Закрыть с результатом «Массовый сбой» без сценария, в том числе не беря в работу | `close` с результатом «Массовый сбой» |
| `incident:reopen` | Вернуть в работу закрытый инцидент | `reopen` Переоткрыть |
| `incident:transfer:own` | Передать своё, ничьё или адресованное мне | `transfer` Передать |
| `incident:transfer:any` | Передать инцидент, занятый другим оператором | `transfer` Передать |
| `incident:reassign` | Перехватить инцидент у работающего оператора | `takeover` Перехватить |
| `incident:bulk` | Обработать несколько инцидентов как один | `merge` Взять в работу |
| `incident:run_action` | Запускать макросы и команды из карточки | `run_macro` Запустить макрос |
| `incident:schema:admin` | Менять схему, нормативы и настройки автоэскалации | не в машине: операции редактора схемы `/operator/workflow/schemas…` (контракт) |
| `agent:set_not_ready` | Переводить себя в перерыв | состояние оператора «Перерыв» (`session`) |
