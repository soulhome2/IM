# Правила перехода состояний МИ

Правила жизненного цикла инцидента в менеджере инцидентов (МИ): ручные действия оператора, эскалация до взятия и настраиваемая автоэскалация по SLA.

## 1. Схема

```
Новое ──Взять──────────────────────────────► В работе ──К очереди──► Приостановлен
  │                                              │                         │
  │                                              │◄──── Возобновить ───────┘
  │                                              │
  ├──Эскалация (до взятия)──┐                    ├──Эскалация (ручная)──┐
  │                         ▼                    │                      ▼
  └──Автоэскалация по SLA──► Эскалация ◄─────────┴──Автоэскалация по SLA┘
                               │
                               └──Перехватить──► В работе ──Закрыть──► Закрыто

Чужое ──Открыть (просмотр)──► … ──Перехватить──► В работе
```

## 2. Состояния

| Состояние | Код | Оператор | Признак паузы | Бейдж в очереди |
|---|---|---|---|---|
| Новое | `new` | нет | — | Новое |
| В работе | `mine` | текущий оператор | `paused = false` | В работе |
| Приостановлен | `mine` | текущий оператор | `paused = true` | Приостановлен |
| Чужое | `foreign` | другой оператор | — | ФИО оператора |
| Эскалация | `escalated` | адресат эскалации | — | Эскалация |
| Закрыто | `closed` | кто закрыл | `paused = false` | Закрыто |

> Приостановлен — это не отдельный `status`, а `mine` + `paused`.

## 3. Кнопки в очереди

| Статус | Основная кнопка | Дополнительно | Результат |
|---|---|---|---|
| Новое | **Взять** | **Эскал.** | Назначение себе **или** эскалация без взятия |
| В работе / Приостановлен (моё) | **Возобновить** | — (эскалация из карточки / `E`) | Снятие паузы и открытие карточки |
| Чужое / Эскалация | **Открыть** | **Перехватить** — в карточке | Просмотр без изменений |
| Закрыто | **Просмотр** | — | Только чтение |

## 4. Переходы по действиям

| Действие | Откуда | Куда | Условие | Что сохраняется |
|---|---|---|---|---|
| **Взять** | Новое | В работе | оператор не на перерыве | оператор = я; сценарий с первого незаполненного шага |
| **Возобновить** | Приостановлен | В работе | оператор не на перерыве | прогресс сценария и текущий шаг |
| **Эскалация (до взятия)** | Новое | Эскалация | ручная; адресат и причина | без назначения себе; прогресс (если был) сохраняется |
| **Эскалация (из карточки)** | В работе / Приостановлен | Эскалация | инцидент мой | прогресс сценария; оператор = адресат |
| **Автоэскалация по SLA** | Новое или В работе / Приостановлен* | Эскалация | настройка включена; `slaSec ≤ 0`; ещё не автоэскалировался | оператор = настроенный адресат; запись в журнал от диспетчера |
| **Открыть** | Чужое / Эскалация | карточка просмотра | всегда | статус не меняется |
| **Просмотр** | Закрыто | карточка только чтения | всегда | статус не меняется |
| **К очереди / Esc** | В работе | Приостановлен | инцидент мой и не на паузе | шаг, ответы, журнал |
| **К очереди** | просмотр чужого / эскалированного / закрытого | очередь | — | статус прежний |
| **Перехватить** | Чужое или Эскалация | В работе | оператор не на перерыве | прогресс сценария; оператор = я |
| **Закрыть** | В работе | Закрыто | заполнены все обязательные шаги сценария | результат в журнал / AxxonData |
| **Обработать как одно** | несколько выбранных (обычно новые) | В работе | ≥ 2 выбранных; не на перерыве | групповое назначение |

\* Состав статусов для автоэскалации настраивается (см. §6). По умолчанию: `new`, `mine`.

## 5. Запреты

| Ситуация | Запрещено |
|---|---|
| Оператор на перерыве | Взять, Возобновить, Перехватить; правки сценария |
| Чужой / уже эскалированный инцидент | правка шагов, закрытие, повторная ручная эскалация без перехвата |
| Закрытый инцидент | любые изменения |
| Обязательные шаги не заполнены | Закрыть |
| Автоэскалация уже сработала | повторный автозапуск по тому же инциденту |

## 6. Автоэскалация по SLA (настраивается)

Параметры задаются в диспетчере событий / фильтре (в прототипе — `SETTINGS.autoEscalate`):

| Параметр | Назначение | Значение по умолчанию (прототип) |
|---|---|---|
| `enabled` | Включить / выключить автоэскалацию | `true` |
| `statuses` | Для каких статусов срабатывает | `["new", "mine"]` |
| `target` | Кому передавать | старший смены / ЦОД |
| `reason` | Текст причины в журнале | «Автоэскалация: превышен норматив реакции (SLA)» |

### Правило срабатывания

1. Таймер норматива (`slaSec`) уменьшается, пока инцидент не закрыт.
2. Когда `slaSec ≤ 0` и статус входит в `statuses`, и флаг `autoEscalated` ещё не установлен:
   - статус → `escalated`;
   - оператор → `target`;
   - `paused = false`;
   - в журнал пишется запись от имени диспетчера;
   - если оператор был в карточке этого инцидента — возврат в очередь.
3. Повторно автоэскалация по этому инциденту не выполняется.

### Возможные расширения настройки (продукт)

- Разные адресаты по приоритету / типу события / объекту.
- Эскалация только «не взятых» (`new`) либо также просроченных «в работе».
- Цепочка уровней (старший смены → ЦОД).
- Уведомление адресата без смены статуса (отдельный режим «алерт», не эскалация).

## 7. Горячие клавиши (релевантные переходам)

| Клавиша | Действие |
|---|---|
| `N` | Взять следующее новое |
| `E` | Эскалация выбранного (новое или своё) |
| `T` | Перехватить чужое / эскалированное |
| `Esc` | Приостановить своё и вернуться к очереди |
| `Enter` | Закрыть (если сценарий заполнен, карточка в работе) |
| `G` | Обработать выделенные как одно |
| `B` | Перерыв / возврат на смену |
