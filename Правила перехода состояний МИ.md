# Правила перехода состояний МИ

Правила жизненного цикла инцидента в менеджере инцидентов (МИ): ручные действия оператора, эскалация до взятия, настраиваемая автоэскалация по SLA и права, которыми ограничены действия над чужими инцидентами.

## 1. Схема

```
Новое ──Взять──────────► В работе ──К очереди / Esc──► Приостановлен
  │                         │   ▲                            │
  │                         │   └────── Возобновить ─────────┘
  │                         │
  │                         └──Закрыть──► Закрыто
  │
  ├──Эскалация (до взятия)───────────┐
  │                                  │
  │  В работе / Приостановлен        │
  │      └──Эскалация (своё)─────────┤
  │                                  ├──► Эскалация
  │  Чужое / Эскалация               │
  │      └──Перенаправить (право)────┤
  │                                  │
  └──Автоэскалация по SLA────────────┘

Чужое / Эскалация ──Открыть (просмотр)──► ──Перехватить (право)──► В работе
```

## 2. Состояния

| Состояние | Код | Оператор | Признак паузы | Бейдж в очереди |
|---|---|---|---|---|
| Новое | `new` | нет | — | Новое |
| В работе | `mine` | текущий оператор | `paused = false` | В работе |
| Приостановлен | `mine` | текущий оператор | `paused = true` | Приостановлен |
| Чужое | `foreign` | другой оператор | — | ФИО оператора |
| Эскалация | `escalated` | адресат эскалации | — | Эскалация |
| Закрыто | `closed` | кто закрыл | `paused = false` | Закрыто |

> Приостановлен — это не отдельный `status`, а `mine` + `paused`.

## 3. Права оператора

Права выдаются роли в системе прав доступа. Если право не выдано, соответствующая кнопка не показывается (или заблокирована), а горячая клавиша не срабатывает. В прототипе — объект `PERMISSIONS`.

| Право | Что разрешает | Ключ (прототип) |
|---|---|---|
| **Брать в работу** | Взять новый инцидент себе, возобновить свой приостановленный | `take` |
| **Приостанавливать** | Отложить свой инцидент и вернуться к очереди | `pause` |
| **Закрывать инцидент** | Завершить обработку с записью результата | `close` |
| **Эскалировать** | Передать другому адресату новый инцидент (до взятия) или свой | `escalate` |
| **Эскалировать чужие** | Перенаправить инцидент, уже взятый другим оператором или эскалированный, без перехвата | `escalateForeign` |
| **Перехватывать** | Забрать себе чужой или эскалированный инцидент | `takeover` |
| **Просматривать чужие** | Открыть карточку чужого инцидента только для чтения (контроль хода обработки) | `viewForeign` |
| **Групповая обработка** | Обработать несколько выбранных инцидентов как один | `groupProcess` |
| **Запускать макросы** | Выполнять команды и макросы из карточки (оповещение, шлагбаум, наряд) | `runMacros` |
| **Уходить на перерыв** | Переводить себя в статус «Перерыв» | `break` |

### Права, которые логично добавить в продукте

- **Настраивать автоэскалацию** — менять параметры из §8 (статусы, срок) и адресат по умолчанию из §7.
- **Настраивать своё рабочее место** — состав и раскладка панелей, горячие клавиши.
- **Смотреть архив и отчёты** — доступ к видеоархиву и выгрузке по закрытым инцидентам.
- **Переоткрывать закрытые** — возврат инцидента в работу после закрытия.
- **Видеть все группы объектов** либо только назначенные смене.

## 4. Кнопки в очереди

| Статус | Основная кнопка | Дополнительно | Требуемые права |
|---|---|---|---|
| Новое | **Взять** | **Эскалация** | `take` / `escalate` |
| Приостановлен (моё) | **Возобновить** | **Эскалация** | `take` / `escalate` |
| В работе (моё) | **Возобновить** | **Эскалация** | `take` / `escalate` |
| Чужое / Эскалация | **Открыть** (просмотр) | **Эскалация** — перенаправление; **Перехватить** — в карточке | `viewForeign` / `escalateForeign` / `takeover` |

Кнопка **Эскалация** оформлена отдельным (оранжевым) цветом: действие передаёт ответственность другому человеку, поэтому визуально отделено и от обычного **Взять** (синий), и от **Перехватить** (красный).
| Закрыто | **Просмотр** | — | — |

## 5. Переходы по действиям

| Действие | Откуда | Куда | Условие и право | Что сохраняется |
|---|---|---|---|---|
| **Взять** | Новое | В работе | `take`; не на перерыве | оператор = я; сценарий с первого незаполненного шага |
| **Возобновить** | Приостановлен | В работе | `take`; не на перерыве | прогресс сценария и текущий шаг |
| **Эскалация (до взятия)** | Новое | Эскалация | `escalate`; указан адресат (см. §7) | без назначения себе; оператор = адресат |
| **Эскалация (своё, из очереди)** | Приостановлен | Эскалация | `escalate` | прогресс сценария; оператор = адресат; оператор остаётся в очереди |
| **Эскалация (своё, из карточки)** | В работе | Эскалация | `escalate` | прогресс сценария; обработка прерывается, возврат к очереди |
| **Перенаправить** | Чужое / Эскалация | Эскалация | `escalateForeign` | прогресс чужой обработки; оператор = новый адресат; перехват не требуется |
| **Автоэскалация по SLA** | Новое, В работе / Приостановлен\* | Эскалация | настройка включена; `slaSec ≤ 0`; ещё не автоэскалировался; права оператора не участвуют | оператор = настроенный адресат; запись в журнал от диспетчера |
| **Открыть** | Чужое / Эскалация | карточка просмотра | `viewForeign` | статус не меняется |
| **Просмотр** | Закрыто | карточка только чтения | всегда | статус не меняется |
| **Перехватить** | Чужое / Эскалация | В работе | `takeover`; не на перерыве | прогресс сценария; оператор = я |
| **К очереди / Esc** | В работе | Приостановлен | `pause`; инцидент мой | шаг, ответы, журнал |
| **К очереди** | просмотр чужого / эскалированного / закрытого | очередь | — | статус прежний |
| **Закрыть** | В работе | Закрыто | `close`; заполнены все обязательные шаги | результат в журнал / AxxonData |
| **Обработать как одно** | несколько выбранных (обычно новые) | В работе | `groupProcess` + `take`; ≥ 2 выбранных; не на перерыве | групповое назначение |

\* Состав статусов для автоэскалации настраивается (см. §8). По умолчанию: `new`, `mine`.

## 6. Запреты

| Ситуация | Запрещено |
|---|---|
| Нет права `take` | Взять, Возобновить, групповая обработка |
| Нет права `pause` | уйти к очереди с незакрытым своим инцидентом — нужно закрыть или эскалировать |
| Нет права `takeover` | Перехватить чужое или эскалированное (остаётся только просмотр) |
| Нет права `escalateForeign` | ручная эскалация чужого или уже эскалированного инцидента |
| Нет права `viewForeign` | открывать карточки чужих инцидентов |
| Оператор на перерыве | Взять, Возобновить, Перехватить; правки сценария и макросы |
| Чужой / эскалированный инцидент | правка шагов, запуск макросов, закрытие (только после перехвата) |
| Закрытый инцидент | любые изменения |
| Обязательные шаги не заполнены | Закрыть |
| Автоэскалация уже сработала | повторный автозапуск по тому же инциденту |

## 7. Адресат эскалации

При ручной эскалации адресат указывается обязательно — в форме появляется список операторов и ролей. Значение по умолчанию подставлено заранее, поэтому в типовом случае оператору достаточно указать причину и подтвердить передачу.

| Правило | Поведение |
|---|---|
| Список адресатов | операторы и роли, которым разрешено передавать инциденты (в прототипе — `OPERATORS`) |
| Предвыбор | адресат по умолчанию из настройки оператора |
| Текущий владелец | исключается из списка при перенаправлении чужого инцидента — передать «самому себе» нельзя |
| Доступность | у адресатов не на смене («по вызову») это указано в строке списка |
| Автоэскалация | использует тот же адресат по умолчанию, без участия оператора |

Настройка по умолчанию живёт в меню оператора (правый верхний угол, рядом с «Уйти на перерыв»): раздел «Эскалация по умолчанию» → «Кому передавать». Одно значение работает и как предвыбор в ручной форме, и как адресат автоэскалации по SLA.

## 8. Автоэскалация по SLA (настраивается)

Автоэскалация выполняется системой, а не оператором, поэтому права оператора её не ограничивают. Параметры задаются в диспетчере событий / фильтре (в прототипе — `SETTINGS.autoEscalate`):

| Параметр | Назначение | Значение по умолчанию (прототип) |
|---|---|---|
| `enabled` | Включить / выключить автоэскалацию | `true` |
| `statuses` | Для каких статусов срабатывает | `["new", "mine"]` |
| `target` | Кому передавать | адресат по умолчанию из меню оператора (§7), изначально — старший смены |
| `reason` | Текст причины в журнале | «Автоэскалация: превышен норматив реакции (SLA)» |

### Правило срабатывания

1. Таймер норматива (`slaSec`) уменьшается, пока инцидент не закрыт.
2. Когда `slaSec ≤ 0` и статус входит в `statuses`, и флаг `autoEscalated` ещё не установлен:
   - статус → `escalated`;
   - оператор → `target`;
   - `paused = false`;
   - в журнал пишется запись от имени диспетчера;
   - если оператор был в карточке этого инцидента — возврат в очередь.
3. Повторно автоэскалация по этому инциденту не выполняется.

### Возможные расширения настройки (продукт)

- Разные адресаты по приоритету / типу события / объекту.
- Эскалация только «не взятых» (`new`) либо также просроченных «в работе».
- Цепочка уровней (старший смены → ЦОД).
- Уведомление адресата без смены статуса (отдельный режим «алерт», не эскалация).

## 9. Горячие клавиши (релевантные переходам)

| Клавиша | Действие | Право |
|---|---|---|
| `N` | Взять следующее новое | `take` |
| `E` | Эскалация выбранного | `escalate`, для чужого — `escalateForeign` |
| `T` | Перехватить чужое / эскалированное | `takeover` |
| `Esc` | Приостановить своё и вернуться к очереди | `pause` |
| `Enter` | Закрыть (если сценарий заполнен, карточка в работе) | `close` |
| `G` | Обработать выделенные как одно | `groupProcess` |
| `B` | Перерыв / возврат на смену | `break` |
| `F1` | Регламент обработки инцидента — из любого места, в том числе из поля ввода | — |
| `?` | Список горячих клавиш | — |
