Фокусировка на реальных проблемах интерфейса и удобстве для пользователя.

1. Сделать единообразие на всех вкладках — дать возможность множественного выбора с чек-боксом «Выбрать все». **Кроме вкладки «Группа доступа».** Как вариант — как выделяются устройства, когда в заголовке столбца рядом с «Имя» есть чекбокс.
2. Вкладку «Группы» переименовать на «Группы устройств».
3. В группах нужно, чтобы можно было выделять устройство и показывалась его карточка. Пока в карточке только название и timestamp (взять с back). В дальнейшем будет дополнительная информация и разные статусы.
4. Сценарии/правила: отображение редактирования/копирования/удаления на каждой строке избыточно. Лучше сделать по аналогии с Gmail для десктопной версии — эти кнопки появляются только при наведении на строку.
5. Предложить решение — как в группах быстро найти устройство. Сейчас это возможно только раскрывая каждую группу и далее либо поиск в ней контролом справа сверху, либо визуально.
6. Редактировать список устройств: при выборе поиска убрать смену размеров контрола, он должен оставаться тем же (зафиксированным). Сейчас размер зависит от числа подошедших под фильтр элементов, в итоге размер «скачет».
7. Единый контрол для **назначения** в группы, в нём же реализуется удаление и перемещение между группами (причём множественное), т.е. пункты «Удаление» и «Перемещение» убираем.
8. Исправить блокировку удаления правила при незавершённом сохранении: убрать ложное состояние гонки или показывать понятное сообщение об ошибке. Сейчас это - "Дождитесь завершения сохранения перед удалением правила." 
9. При редактировании привязок при сохранении не должно быть дублирующих условий. Проверка на уникальность при сохранении.
10. Группы доступа: поиск должен работать по всему, не только по имени групп, т.е. по добавленным условиям также — с раскрытием группы при нахождении (например, вводим название камеры и находим, в каких группах она привязана).
11. Для групп доступа нужна визуальная сортировка asc/desc.
12. Для групп нужно добавить поле «Описание», чтобы пользователь мог указать детали — что это за группа. При наведении на группу появляется подсказка с описанием, если оно задано и не пустое. Кейс: юзер быстро проводит мышкой по группам, и интерфейс без задержек показывает её описание.
13. Для сценариев нужен столбец "Пользователь" — какой пользователь его редактировал (последним).
14. Для правил нужен столбец «Пользователь» + «Изменено» (аналогично сценариям).
15.  Для групп доступа нужен столбец «Пользователь» + «Изменено» (аналогично сценариям).
